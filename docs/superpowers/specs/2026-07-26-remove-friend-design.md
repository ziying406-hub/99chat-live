# 删除好友设计

## 目标

让任一好友可以解除双方好友关系，并保证通讯录、私聊发送权限和多端实时状态一致。

## 行为

- 在私聊设置中提供“删除好友”操作，并要求二次确认。
- 删除由任意一方发起，双方的联系人列表都会移除对方。
- 既有私聊消息仍可查看，历史不会被删除。
- 被解除后，私聊输入区显示“你们已不是好友，无法发送消息”。
- 后端拒绝任何解除后的私聊发送，避免仅靠前端限制被绕过。
- 双方收到实时好友状态更新，联系人列表无需刷新即可同步。

## 接口与实现边界

- 新增 `DELETE /api/contacts/{id}`，只允许删除当前用户自己的联系人关系。
- 使用现有联系人存储与实时好友事件机制；不新增数据表，也不删除会话或消息。
- 前端复用现有会话设置样式和错误提示，避免额外页面。

## 验收

1. A 删除 B 后，A 与 B 的通讯录都不再出现对方。
2. A 与 B 都不能再向该私聊发送新消息，服务端返回拒绝。
3. 历史私聊仍能打开与查看。
4. 页面已打开的另一端无需刷新即可同步到解除状态。
